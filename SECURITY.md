# Security policy

This project is educational and is not intended to process untrusted network traffic
or real orders without additional validation and operational controls.

Please report suspected memory-safety, persistence-integrity, or denial-of-service
issues privately through GitHub's security-advisory feature rather than a public
issue. Include a minimal reproducer, affected revision, compiler, and platform when
possible.

Only the latest revision is maintained. No response-time or production-support SLA
is offered.
